# Personal Finance Manager — Smart Offline Edition
> **স্মার্ট অফলাইন পার্সোনাল ফাইন্যান্স ম্যানেজার**  
> ১০০% অফলাইন, সম্পূর্ণ নিরাপদ, দ্বিভাষিক (বাংলা ও ইংরেজি), জিরো-কস্ট একক ব্যবহারকারী আর্থিক খতিয়ান ও বিশ্লেষণ অ্যাপ্লিকেশন।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Highlights)

- ⚡ **১০০% অফলাইন ও ব্রাউজার-ভিত্তিক (Zero-Cost):** কোনো ক্লাউড সার্ভার, ডেটাবেজ সাবস্ক্রিপশন বা ইন্টারনেটের প্রয়োজন নেই।
- 🔒 **কঠোর নিরাপত্তা ও MIS গেট (Rule 5 & Section 17):** কোনো লেনদেন, রেকর্ড বা ব্যাকআপ মোছার জন্য **MIS Module Password** বাধ্যতামূলক। কোনো হিডেন বাইপাস নেই।
- 💰 **পয়সা নির্ভুলতা (Integer Minor Units):** IEEE 754 ফ্লোটিং পয়েন্ট হিসাবের গরমিল রোধে প্রতি পয়সার হিসাব নিখুঁত পূর্ণসংখ্যায় সংরক্ষিত।
- 🇧🇩 **দ্বিভাষিক ইন্টারফেস (Bilingual Interface):** বাংলা এবং ইংরেজি দুটি ভাষার পূর্ণ সমর্থন। ডিফল্ট মুদ্রা বাংলাদেশি টাকা (৳ BDT) এবং সময় অঞ্চল Asia/Dhaka।
- 📊 **নেটিভ অফলাইন চার্ট ও রিপোর্ট:** কোনো বহিরাগত সিডিএন ছাড়া অফলাইন SVG বার ও ডোনাট চার্ট।
- 📑 **নিরাপদ এক্সপোর্ট (CSV & Excel XML):** এক্সেল-এ বাংলা অক্ষুণ্ণ রাখতে UTF-8 BOM (`\uFEFF`) যুক্ত CSV ও স্প্রেডশিট এক্সপোর্ট, ডাউনলোড পূর্ববর্তী ডেটা প্রিভিউ এবং পাসওয়ার্ড ফিল্টারিং।
- 💾 **সামরিক মানের ব্যাকআপ ও রিস্টোর:** সম্পূর্ণ JSON ব্যাকআপ, ঐচ্ছিক **AES-256-GCM** এনক্রিপশন, SHA-256 চেকসাম, রিস্টোর পূর্ববর্তী যাচাই এবং জরুরি অটো-সেফটি স্ন্যাপশট।
- 🤖 **অফলাইন এআই সহকারী ও হেলথ স্কোরকার্ড:** সঞ্চয় হার (Savings Rate), জরুরি রিজার্ভ (Emergency Buffer in Months), বাজেট অ্যালার্ট ও ঋণ পরিশোধের তাগিদ।
- 🛡️ **জিরো-ডেমো নীতি (Zero-Demo Policy):** নতুন ইনস্টলেশনে কোনো ভুয়া লেনদেন যুক্ত হয় না; এটি সম্পূর্ণ পরিষ্কারভাবে শুরু হয়।

## 🚀 দ্রুত চালু করার নির্দেশিকা (How to Run)

### পদ্ধতি ১: ১-ক্লিক স্টার্ট (সুপারিশকৃত)
1. ফোল্ডারে থাকা `start.bat` ফাইলে ডাবল-ক্লিক করুন (অথবা `start.ps1`-এ ডান ক্লিক করে "Run with PowerShell" নির্বাচন করুন)।
2. অ্যাপ্লিকেশনটি স্বয়ংক্রিয়ভাবে একটি লোকাল সার্ভার চালু করে আপনার ডিফল্ট ব্রাউজারে `http://127.0.0.1:8989/` খুলে দেবে।

### পদ্ধতি ২: সরাসরি ব্রাউজারে ওপেন
- যে কোনো আধুনিক ব্রাউজারে (Microsoft Edge, Google Chrome, Mozilla Firefox) `index.html` ফাইলটি ওপেন করুন।

## 📱 মোবাইলে ইনস্টল ও ব্যবহারের পূর্ণাঙ্গ নির্দেশিকা (Android Mobile & PWA Guide)

এই অ্যাপ্লিকেশনটি একটি পূর্ণাঙ্গ **Progressive Web App (PWA)**। এটি সাধারণ কোনো ওয়েবসাইটের মতো নয়—বরং আপনার অ্যান্ড্রয়েড ফোনে একটি স্বতন্ত্র অ্যাপ্লিকেশনের (App) মতো হোম স্ক্রিনে ইনস্টল করা যায়, আইকন প্রদর্শিত হয় এবং সম্পূর্ণ অফলাইনে কাজ করে।

### পদ্ধতি ১: GitHub Pages-এ সম্পূর্ণ ফ্রি ও নিরাপদ হোস্টিং (সুপারিশকৃত)
যেহেতু ব্রাউজারের সিকিউরিটি পলিসি অনুযায়ী PWA ইনস্টলেশনের জন্য **HTTPS** প্রোটোকল প্রয়োজন, তাই আপনি বিনামূল্যে GitHub Pages ব্যবহার করে আপনার কোড ফাইলগুলো হোস্ট করতে পারেন:

1. **গিটহাব রিপোজিটরি তৈরি করুন:**
   - [GitHub.com](https://github.com)-এ যান এবং একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `personal-finance-manager`)। রিপোজিটরিটি **Public** বা **Private** রাখতে পারেন।
2. **ফাইলগুলো আপলোড করুন:**
   - আপনার এই ফোল্ডারের সমস্ত ফাইল ও সাবফোল্ডার (`index.html`, `manifest.json`, `sw.js`, `icons/`, `js/`, `css/`) রিপোজিটরিতে আপলোড/পুশ করুন।
3. **GitHub Pages চালু করুন:**
   - রিপোজিটরির **Settings** > **Pages** ট্যাবে যান।
   - **Branch** হিসেবে `main` (বা `master`) এবং ফোল্ডার `/ (root)` নির্বাচন করে **Save** বাটনে ক্লিক করুন।
   - ২-৩ মিনিটের মধ্যে আপনাকে একটি লিংক দেওয়া হবে (যেমন: `https://<your-username>.github.io/personal-finance-manager/`)।
4. **অ্যান্ড্রয়েড ফোনে ইনস্টল করুন:**
   - আপনার মোবাইলের Google Chrome ব্রাউজারে লিংকটি ওপেন করুন।
   - ব্রাউজারের উপরে **"📲 ইনস্টল করুন"** বাটন দৃশ্যমান হবে (অথবা ক্রোম ব্রাউজারের ডানদিকের ৩-ডট মেনু `⋮`-এ ট্যাপ করে **"Install app"** বা **"Add to Home screen"** নির্বাচন করুন)।
   - এটি আপনার ফোনের অ্যাপ ড্রয়ার ও হোম স্ক্রিনে ইনস্টল হয়ে যাবে।
   - **পরবর্তীকালে ইন্টারনেট বন্ধ থাকা অবস্থাতেও** হোমস্ক্রিনের আইকন থেকে অ্যাপটি নিমিষেই চালু করতে পারবেন।

> [!IMPORTANT]
> **গোপনীয়তা ও ডেটা সুরক্ষার নিশ্চয়তা (Zero-Cloud Privacy Guarantee):**  
> GitHub Pages শুধুমাত্র অ্যাপ্লিকেশনের ডিজাইন ও কোড ফাইলগুলো (HTML/CSS/JS) ব্রাউজারে সরবরাহ করে। আপনার সমস্ত ব্যক্তিগত আর্থিক লেনদেন, হিসাব, জমা-খরচ এবং MIS পাসওয়ার্ড **কখনোই গিটহাবে বা ইন্টারনেটে আপলোড হয় না**। সমস্ত আর্থিক তথ্য সম্পূর্ণ সুরক্ষিতভাবে আপনার ফোনের নিজস্ব ব্রাউজার স্টোরেজে (IndexedDB) থাকে।

### পদ্ধতি ২: কম্পিউটার থেকে লোকাল ওয়াইফাই (LAN)-এর মাধ্যমে ফোনে ব্যবহার
কম্পিউটার এবং মোবাইল একই ওয়াইফাই নেটওয়ার্কে যুক্ত থাকলে:
1. কম্পিউটারের লোকাল IP অ্যাড্রেস জানুন (যেমন: `ipconfig` কমান্ডের মাধ্যমে IPv4 অ্যাড্রেস, যেমন `192.168.0.105`)।
2. কম্পিউটারে `start.bat` চালু রাখুন।
3. মোবাইলের ব্রাউজারে `http://192.168.0.105:8989/` লিখুন।
4. ব্রাউজারের ৩-ডট মেনু `⋮` থেকে **"Add to Home screen"** ট্যাপ করে শর্টকাট তৈরি করে নিন।

|---|---|---|
| **01** | **ড্যাশবোর্ড (Dashboard)** | নির্বাচিত সময়কালের মোট আয়, ব্যয়, নেট ক্যাশ ফ্লো, বর্তমান ব্যালেন্স, সাম্প্রতিক লেনদেন ও চার্ট। |
| **02** | **আয় যুক্ত করুন (Income)** | তারিখ, পরিমাণ, খাত, উৎস হিসাব ও বিবরণসহ আয়ের এন্ট্রি এবং নিশ্চিতকরণ প্রিভিউ। |
| **03** | **ব্যয় যুক্ত করুন (Expenses)** | খাবার, বাসস্থান, যাতায়াত, কেনাকাটা ইত্যাদি ১২+ কনফিগারযোগ্য খাতে ব্যয় সংরক্ষণ। |
| **04** | **লেনদেন খতিয়ান (Ledger)** | তারিখ অনুযায়ী ফিল্টারিং, অনুসন্ধান, রিভার্সাল ও অডিট হিস্ট্রিসহ সমন্বিত খতিয়ান। |
| **05** | **বাজেট ব্যবস্থাপনা (Budgets)** | খাতভিত্তিক মাসিক বাজেট নির্ধারণ, খরচ পর্যবেক্ষণ ও ৮০% এবং ১০০%+ অতিক্রমের সতর্কবার্তা। |
| **06** | **সঞ্চয় লক্ষ্য (Savings Goals)** | লক্ষ্যমাত্রা, অর্জনের তারিখ এবং দৈনন্দিন খরচযোগ্য তহবিল থেকে সম্পূর্ণ পৃথকীকৃত সঞ্চয়। |
| **07** | **ধার প্রদান (Lending)** | অন্যকে ধার দেওয়া অর্থ, কিস্তি আদায় এবং অতিরিক্ত আদায় রোধের গাণিতিক নিয়ন্ত্রণ। |
| **08** | **ঋণ গ্রহণ (Borrowing)** | অন্যের থেকে ঋণ গ্রহণ, বকেয়া দায় ও পরিশোধ (এটি অর্জিত আয়কে প্রভাবিত করে না)। |
| **09** | **হিসাব ও নগদ (Accounts & Cash)** | নগদ, ব্যাংক ও মোবাইল ব্যাংকিং ব্যালেন্স এবং আয়-ব্যয় স্ফীতিহীন অভ্যন্তরীণ ফান্ড ট্রান্সফার। |
| **10** | **রিপোর্ট ও অডিট (Reports)** | দৈনিক, মাসিক ও বার্ষিক রিপোর্ট, অফলাইন SVG চার্ট, CSV/Excel এক্সপোর্ট ও ডাবল-এন্ট্রি কোয়ালিটি অডিট। |
| **11** | **এআই সহকারী (AI Assistant)** | সঞ্চয় হার, জরুরি রিজার্ভ মাস, স্পেন্ডিং ডমিন্যান্স ও গোপনীয়তামুখী লোকাল LLM প্রম্পট। |
| **12** | **ব্যাকআপ ও রিস্টোর (Backup)** | পূর্ণাঙ্গ JSON ও AES-256-GCM এনক্রিপ্টেড ব্যাকআপ, প্রিভিউ মোডাল ও জরুরি প্রি-রিস্টোর স্ন্যাপশট। |
| **13** | **সেটিংস ও নিরাপত্তা (Settings)** | ভাষা পরিবর্তন, মুদ্রা, টাইমজোন ও MIS পাসওয়ার্ড পরিবর্তন। |

## 🔒 নিরাপত্তা বিধি ও MIS পাসওয়ার্ড (Safety & MIS Rules)

1. **বিধি ৫ (Rule 5):** লেনদেন মুছে ফেলা, অ্যাকাউন্ট ডিলিট বা ডেটাবেজ রিসেটের প্রতিটি অপারেশনের জন্য **MIS Module Password** যাচাই বাধ্যতামূলক।
2. **বিধি ৬ (Rule 6):** কোনো লেনদেন সংশোধনের ক্ষেত্রে পূর্ববর্তী রেকর্ড অডিট লগে সংরক্ষিত থাকে।
3. **বিধি ৯ (Rule 9):** ব্যাকআপ তৈরির পর স্বয়ংক্রিয় মেমোরি ভ্যালিডেশন পাস না হওয়া পর্যন্ত সফল ঘোষণা করা হয় না।
4. **বিধি ১১ (Rule 11):** এক্সপোর্ট ফাইল বা স্ক্রিন ভিউতে কখনোই পাসওয়ার্ড হ্যাশ বা ক্রিপ্টোগ্রাফিক সিক্রেট দৃশ্যমান করা হয় না।
5. **বিধি ১৫ (Rule 15):** কোনো ব্যাকআপ রিস্টোর বা রিসেটের পূর্বে বর্তমান ডেটার একটি জরুরি স্ন্যাপশট স্বয়ংক্রিয়ভাবে ডাউনলোড হয়।

## 🧪 স্বয়ংক্রিয় টেস্ট যাচাই (Automated Test Suite)

অ্যাপ্লিকেশনটিতে **৪২টি স্বয়ংক্রিয় টেস্ট** অন্তর্ভুক্ত রয়েছে যা হেডলেস মাইক্রোসফ্ট এজে ১০০% সফলতার সাথে উত্তীর্ণ হয়েছে।

টেস্ট যাচাই চালাতে ব্রাউজারে প্রবেশ করুন:
`http://127.0.0.1:8989/tests/test_suite.html`

```
Test Results: Total: 42 | Passed: 42 | Failed: 0 (Pass Rate: 100%)
```

## 🛠️ প্রযুক্তি স্ট্যাক (Technology Architecture)

- **Frontend Core:** HTML5, Modern Responsive CSS3 (CSS Grid/Flexbox), Native JavaScript (ES6 Modules)
- **Local Storage:** IndexedDB (Client-Side Structured Object Stores)
- **Cryptography:** Native Web Crypto API (`subtle.deriveBits`, `subtle.digest`, `subtle.encrypt`, PBKDF2-SHA256, AES-256-GCM)
- **Visual Analytics:** Native Offline SVG Rendering (Bar Charts & Donut Charts)
- **Offline Reliability:** Service Worker (Cache Storage v6) & Web App Manifest
- **Platform:** Works on Windows, macOS, Linux, Android, iOS.
